La démarche

Votre assiette n'est pas
un modèle économique.

Ce qu'on voit trop souvent

  • Des listes de courses qui poussent vers une enseigne partenaire.
  • Vos habitudes alimentaires analysées, revendues, ciblées.
  • Un abonnement pour débloquer… votre propre planning.
  • Des suggestions opaques dont personne ne sait expliquer l'ordre.
  • Vos recettes enfermées : le jour où le service ferme, elles disparaissent.

Ce que fait Manger!

  • Une liste de courses neutre, à partager où vous voulez. Aucune enseigne, aucune commande.
  • Une base sur votre machine, SQLite ou PostgreSQL. Personne d'autre ne la lit.
  • Gratuit et libre, sous licence AGPL. Pour toujours.
  • Des suggestions explicables, avec des règles écrites noir sur blanc.
  • Tout est exportable : recettes en JSON, semaine en ICS, sauvegarde complète du foyer.
01

Chez vous

Un conteneur Docker sur un mini-PC, un NAS ou un petit serveur. Vous gardez la main sur les données et sur les sauvegardes.

02

Dans la poche

Conçu d'abord pour le téléphone, s'installe sur l'écran d'accueil. On planifie dans le canapé, on coche la liste dans les rayons, même sans réseau.

03

Sans cloud imposé

Polices, icônes et calculs sont locaux. L'import d'une recette par lien ou l'envoi d'un courriel ne se font que si vous les déclenchez ou les configurez.

04

Transparent

Si Manger! vous propose un plat, il sait vous dire pourquoi. Pas de boîte noire, pas d'algorithme d'engagement, pas d'IA générative.

05

Privé par défaut

Pas d'inscription publique ni de mot de passe par défaut : on entre dans le foyer sur invitation, et vos recettes de famille restent à vous.

06

Honnête

La documentation dit ce qui est livré, ce qui ne l'est pas et ce qui n'a pas été testé. Aucun avis, note ou photo inventés.

Ce que ça fait

Toute la vraie vie
tient dans la semaine.

Parce qu'on ne cuisine pas tous les soirs. Il y a le resto du mercredi, le dîner en amoureux, les restes du lendemain, les potes qui débarquent samedi. Manger! planifie les repas comme ils se passent vraiment.

📅

Midi et soir, semaine après semaine

Choisissez une recette pour un créneau, déplacez-la, copiez-la. Laissez Manger! composer les créneaux libres avec un aperçu modifiable, réutilisez une semaine ou l'une de vos semaines types.

🍽️

Maison, extérieur ou restaurant

Un soir dehors n'est pas un trou dans le planning : c'est un repas. Notez le nom du restaurant, le nombre de personnes, c'est tout. Pas de carte, pas de géolocalisation, pas de compte chez un fournisseur.

🕯️

Dates, invités et restes

Un date au restaurant ou autour d'un plat mijoté, des invités autour d'une recette ou d'une commande. Et les restes se planifient : ingrédients achetés le jour où l'on cuisine, jamais comptés deux fois.

🛒

La liste de courses s'écrit toute seule

Ingrédients additionnés, unités compatibles regroupées, rangés par rayon. Cochez en magasin, même hors connexion, partagez ce qu'il reste à acheter. Sans rien ressaisir.

    Foyers mixtes

    Une seule base.
    Chacun sa protéine.

    « J'aime les graines », « Veggie cool », « Team océan » ou « Je mange de tout » autour de la même table ? Manger! enregistre le régime et les goûts de chacun, puis ajoute à la base commune un supplément de protéine compatible pour chaque assiette. Ou prévoit une recette différente par personne, le même soir.

    🍚 Bowl riz & légumes rôtis base commune · végétale

    Touchez un régime pour le changer, ou une protéine pour en essayer une autre compatible. Les quantités suivent dans les courses.

    Anti-gaspi et suggestions

    Le placard d'abord.
    Du bon sens, écrit en clair.

    Notez ce qu'il reste dans le placard, avec une date « à utiliser d'ici le » si vous voulez. Les courses déduisent ces stocks, et les suggestions les mettent en avant. Le classement n'utilise aucune IA : mêmes données, même résultat.

    1. 1

      Filtres stricts : régime de chaque convive et temps disponible.

    2. 2

      Les goûts des participants classent sans exclure : on sait toujours pourquoi un plat descend.

    3. 3

      Un plat pas encore prévu cette semaine passe avant les doublons.

    4. 4

      Priorité aux ingrédients du placard, surtout ceux à utiliser bientôt, puis à ceux déjà achetés pour la semaine.

    5. 5

      Les plats jamais ou pas récemment mangés avant les autres, puis l'ordre alphabétique. Oui, c'est tout.

    Installer

    Quatre lignes.
    Et c'est à table.

    Sur un serveur, un NAS ou simplement votre ordinateur, avec Docker Engine et Compose. Le service écoute sur le port 3000 ; le volume manger-data conserve vos données entre les mises à jour.

    • Aucun mot de passe par défaut : la dernière commande crée le premier administrateur et affiche son mot de passe, à garder dans un gestionnaire.
    • HTTPS local optionnel, à configurer explicitement.
    • Mise à jour : sauvegardez d'abord, ne supprimez jamais les volumes.

    À garder sur un réseau de confiance. Manger! est fait pour le réseau local ou un VPN : ne l'exposez pas directement à Internet.

    sur votre serveur 
    # 1. Récupérer le code (dépôt principal sur Codeberg)
$ git clone -b development https://codeberg.org/LION_LAB/manger.git
$ cd manger

# 2. Lancer
$ docker compose up -d --build

# 3. Créer le premier administrateur
$ docker compose exec manger node accounts.js create-admin admin

✓ Manger! écoute sur le port 3000

    Où on en est

    Honnête, comme le reste.

    Manger! est utilisé au quotidien et en développement actif. La documentation distingue ce qui est livré de ce qui ne l'est pas, et ce qui n'a pas encore été vérifié en conditions réelles.

    1. Parcours de base : recettes, semaine, sorties, courses
    2. Foyers mixtes : régimes, goûts, protéines, restes
    3. Comptes, invitations, sauvegarde et restauration
    4. Catalogue de 100 recettes, placard anti-gaspi et saisons
    5. Hors connexion, HTTPS local, parcours validé sur iPhone
    6. PostgreSQL mis en service sur un réseau local
    7. Image Docker préconstruite publiée
    8. Interfaces tablette et ordinateur, plusieurs foyers par instance
